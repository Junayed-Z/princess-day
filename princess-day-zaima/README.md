# For Zaima, My Princess ♡

A personalized pink-and-lavender Princess Day website, built with HTML, CSS and JavaScript. Free to host on GitHub Pages.

## Before publishing: add your photo and song

Inside the `assets` folder, add:

- `zaima.png` — her original photo (already included). The site displays it as-is; it does not alter her face, clothes or appearance.
- `music.mp3` — the romantic song you want to use. Choose an audio file you have permission to use.

The song does not autoplay. She can tap **Play our song** after opening the invitation; browsers require a user interaction before audio can play.

## Personalize the letter

Open `index.html` and edit the text inside `<div class="letter-text">`. You can change the wording, add a private memory, or make the letter more personal.

## Publish it free with GitHub Pages

1. Sign in to https://github.com/
2. Create a new **Public** repository, for example `princess-day`.
3. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder (with your photo and MP3).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait for GitHub to publish it. Your address will look like `https://YOUR-USERNAME.github.io/princess-day/`.

Open the link on your phone and test the photo, music and invitation before sharing it.

## Important

Keep private photos and personal information out of a public repository if you do not want them publicly accessible. GitHub Pages websites in public repositories can be viewed by anyone with the link (and potentially discovered by others).
